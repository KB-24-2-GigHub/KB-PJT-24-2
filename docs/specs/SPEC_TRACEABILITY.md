### `8.0.0` 이전 기준 감사 (역사)

감사 기준은 `dev2@b0e34fec5604169e96ecc33df9d69428f81d48a4`와 2026-08-10 GitHub
상태입니다. `Implemented`는 코드와 검증으로 확인, `Partial`은 일부 경로만 존재,
`Planned`는 기존 기능 이슈 소유이나 현재 제품 경로 부재, `Blocked`는 선행 제품 결정 또는
소유 작업이 필요함을 뜻합니다. `Refactoring`은 기능 상태가 아니라 별도 열의 구조 변경
Overlay이며 Refactoring 이슈가 닫혀도 기능 상태가 자동으로 올라가지 않습니다.

`7.0.0`은 M6 Settlement와 M7 문서·뱃지 관련 행을 2026-08-12 GitHub 상태로 다시
확인했고, `7.0.1`은 `dev2@626c013aaf183b0e671c28a62983be5d65bf8c65`에서 WORKER
홈·이력 Backend와 SHARED 문서 상세 문맥을 추가 감사했습니다. `8.0.0`은
`dev2@9b6ce3fa0d54e4022d932154814d0d4bef4fa770`에서 #328과 직접 연결된 임금·정산 행만
재감사했습니다. 등록·수정·초대·조회는 `dailyWage`와 `work_cases.agreed_wage`, OWNER 정상
정산은 원 예치액 전액 지급·환불 0원으로 정렬됐지만 Frontend의 시간 경과 확보 금액 표시는
별도 잔여 공백입니다. 나머지 행은 위 2026-08-10 감사 기준점을 유지합니다. 승인된 Patch는
