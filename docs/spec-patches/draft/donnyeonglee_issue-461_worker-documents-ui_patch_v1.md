# SPEC-461-01: 문서함 표시 파일명 간소화·발급일 입력 캘린더 통일·유형 뱃지 도입

## 추가 사항

DOC-001이 정의한 문서 목록·상세 조회(`GET /api/documents`, `GET /api/documents/{id}`)가
돌려주는 `fileName` 필드의 조립 방식과, 알바생·사장님 문서함 화면(`WorkerDocumentsView`,
`OwnerDocumentsView`)의 표시 방식을 바꾼다. 목록·상세가 반환하는 문서 데이터(문서 자체,
승인 필드 목록, 권한 계산)는 바꾸지 않는다 — `fileName` 필드의 문자열 내용과 화면
표시 방식만 바뀐다.

- **`fileName` 간소화**: 카드에 발급일이 별도로 표시되므로, 서버가 조립하는
  `fileName`에서 발급일 세그먼트를 뺀다.
  - 보건증: `보건증_{발급일}_{이름}` → `보건증_{이름}`
  - 근로계약서: `근로계약서_{지점명}_{발급일}_{이름}` → `근로계약서_{지점명}_{이름}`
  - 파일 다운로드 시 Content-Disposition 헤더 파일명(`DocumentFileAccessService`)은
    바꾸지 않는다 — 프론트엔드 다운로드 버튼이 이 헤더 대신 목록/상세가 준 `fileName`을
    저장 파일명으로 쓰기 때문에, 실제 저장 파일명은 이번 변경으로 함께 바뀐다.
- **발급일 입력 캘린더 통일**: 알바생 문서함의 보건증 등록 시트·발급일 수정 모달에서
  발급일을 입력하는 UI를 브라우저 기본 date input(`input[type=date]`)에서,
  #432(SPEC-432-02)가
  근무 등록 화면에 도입한 월 그리드 캘린더 바텀시트(`AppDateFieldCalendar`)로 바꾼다.
  서버로 보내는 `issuedDate` 값의 형식("YYYY-MM-DD")과 DOC-005·DOC-006의 검증 규칙은
  바꾸지 않는다.
- **문서 유형 뱃지**: 알바생·사장님 문서함 카드 좌측의 이미지/PDF 구분 아이콘을 없애고,
  근로계약서/보건증을 구분하는 문서 유형 텍스트 뱃지로 바꾼다. 두 화면 모두 두 뱃지의
  폭을 동일하게 맞추고, 근로계약서 뱃지는 파란색 계열을 쓴다(사장님 화면은 보건증
  뱃지도 이미 같은 파란 계열이라 색만으로는 구분되지 않으며, 텍스트로 구분한다).
- **카드 메타 정보 줄 재구성**: "발급일 · 유형 · 만료일"을 한 줄로 잇던 표시를
  `발급일: {날짜}` / `만료일: {날짜}`(만료일이 있을 때만) 두 줄로 나누고, 뱃지와
  중복되는 유형 텍스트는 뺀다.

## 완료 조건

- [x] 문서 목록·상세 응답의 `fileName`이 보건증은 `보건증_{이름}`, 근로계약서는
      `근로계약서_{지점명}_{이름}` 형식이며 발급일을 포함하지 않는다.
- [x] 실제 파일 다운로드 시 저장되는 파일명도 위와 동일한 형식이다.
- [x] 알바생 문서함의 보건증 등록·발급일 수정에서 날짜를 월 그리드 캘린더 바텀시트로
      고르며, 서버로 전송되는 `issuedDate` 형식은 변경 전과 동일하다.
- [x] 알바생·사장님 문서함 카드에 문서 유형 텍스트 뱃지가 표시되고, 두 뱃지의 폭이
      동일하다.
- [x] 카드에 `발급일: ...` 줄이 항상 표시되고, `만료일: ...` 줄은 만료일이 있는
      문서(현재는 보건증)에만 표시된다.
